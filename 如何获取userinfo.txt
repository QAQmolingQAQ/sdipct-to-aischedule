如何获取 userinfo.json（小爱课程表调试数据）
================================================================

本工具推送课表到小爱课程表时，需要一份“UserInfo”调试数据（内含登录令牌），
请把它保存为项目目录下的 userinfo.json。

    d:\ai\xiaoaikechnegbiao\sdipct-to-aischedule\userinfo.json

下面分别说明“MIUI / HyperOS 系统自带版”和“小爱课程表独立版”，操作基本相同。


----------------------------------------------------------------
一、准备工作
----------------------------------------------------------------
- 手机已安装并登录小爱课程表：
    · 系统自带版：在手机系统里直接打开“小爱课程表”
    · 独立版 App：需先登录小米账号
- 电脑上已解压 / 克隆本项目，并已 pip install -r requirements.txt


----------------------------------------------------------------
二、在手机上获取 UserInfo
----------------------------------------------------------------
1. 打开小爱课程表，点击右下角“头像 / 设置”按钮，进入课程表设置页。

2. 把设置页一直向下滑到最底部。

3. 在“开始新学期”按钮【下方】的空白处，连续快速点击 5 次。
   - 点对了会自动跳转到 Debug 页面；
   - 没反应就再多点几次（注意点的是空白区域，不是按钮本身）；
   - 部分机型需要点设置页最底部一点点位置。

4. 在 Debug 页面中点击“点击获取 UserInfo”。

5. 弹出的窗口中点击“复制”，此时剪贴板里是一整行 JSON 文本。


----------------------------------------------------------------
三、保存为 userinfo.json
----------------------------------------------------------------
1. 把复制到的内容，【原样】粘贴到一个新建的文本文件里：
   - 必须是一整行 JSON，不要手动换行、不要加注释；
   - 不要只复制其中一部分。

2. 另存为 userinfo.json，放到项目目录（编码选 UTF-8）：

       d:\ai\xiaoaikechnegbiao\sdipct-to-aischedule\userinfo.json

3. 正确的内容形如（下面只是示例，实际值会不同）：

       {"serviceToken":"...","cUserId":"...","userId":1234567890,
        "deviceId":"...","sid":"...","security":"...","slh":"...",
        "ph":"...","peeked":true,"authorization":"DO-TOKEN-V1 ...",
        "userAgent":"REDMI ..."}

   注意：真实文件应当只有一行，上面的换行只是为了方便阅读。


----------------------------------------------------------------
四、校验是否获取成功
----------------------------------------------------------------
在项目目录执行：

    python -c "import json;from aischedule_push import AiSchedulePusher;print(AiSchedulePusher(json.load(open('userinfo.json',encoding='utf-8'))).kind)"

- 正常会打印：
      MIUI系统自带小爱课程表
  或
      小爱课程表独立版

- 若报错“UserInfo 字段缺失，无法识别来源”，说明内容不完整
  （常见是只拿到了 userId / deviceId，缺少 authorization 或 userAgent），
  请回到第二步重新获取，并确认整行 JSON 都粘贴完整。


----------------------------------------------------------------
五、安全提示
----------------------------------------------------------------
- userinfo.json 内含登录令牌（access_token），等同于你的账号登录态。
- 本项目已在 .gitignore 中忽略该文件，请勿上传到 GitHub、也不要发给他人。
- 令牌会过期。如果推送时提示鉴权失败，重新获取一次即可。


----------------------------------------------------------------
六、常见问题
----------------------------------------------------------------
Q：点了 5 次没反应？
A：确认点的是“开始新学期”【下方】的空白区域；先确认页面已滑到最底部；
   实在不行换个位置多试几次。

Q：独立版 App 找不到“头像 / 设置”？
A：请先登录小米账号，再进入课程表设置页。

Q：新版 App 找不到 Debug 入口？
A：部分版本移除了连点 5 次的入口，可尝试安装旧版小爱课程表；
   或在系统自带版（MIUI / HyperOS）中操作。

Q：粘贴后 json 解析报错？
A：多半是复制不完整或中途换行，请重新“复制”后一次性完整粘贴。
